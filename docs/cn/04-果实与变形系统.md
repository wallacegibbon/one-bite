# 04 · 果实与变形系统

[English: ../en/04-fruit-and-transformation.md](../en/04-fruit-and-transformation.md)

数据真源：`game/data/fruits.js`。文档中的每个数字都直接来自该文件。

## 1. 稀有度：容量与保质期

稀有度不是"价值等级"，是**两个物理参数**：

| 稀有度 | 中文 | 占果格 | 失活时间 | 重新结果 | 环色 |
|---|---|---|---|---|---|
| common | 常见 | **1** | 1500 s（25 分） | 1.0 游戏日 | `#9ab97e` |
| uncommon | 少见 | **2** | 1200 s（20 分） | 1.5 游戏日 | `#6cb4f0` |
| rare | 稀有 | **4** | 900 s（15 分） | 2.0 游戏日 | `#b987f2` |
| epic | 极稀 | **7** | 600 s（10 分） | 2.5 游戏日 | `#ff9c4a` |
| legendary | 传说 | **12** | 420 s（7 分） | 3.0 游戏日 | `#ffdc5c` |

**背包 24 格** → 一次最多装：24 常见 / 12 少见 / 6 稀有 / 3 极稀 / **2 传说**。

一条关键推论：一颗焰心果（12 格）+ 一颗母树花蕾（12 格）= 背包全满，**没有任何空间带补给**。这就是终章"嫁接"路线的物理难度。

### 1.1 重新结果（Regrow）

摘掉的果实方块不会永久消失——母树的根系会把养分重新送回去。所需时间按稀有度排（见上表），实际值在 ±20% 内随机，避免同一批果实同时成熟。规则：

- 只有**果实方块**会重生；蘑菇、发光种子等植物不重生（否则窖树种可无限刷）。
- 重生计时在**存档里保存**，退出游戏期间不推进——谷地不等你。
- 若原位置已被别的方块占住（玩家砍了树、熊撞塌了枝），这次重生**作废**，不硬塞。
- 设计意图：谷地不会被掏空，但"昨天那棵"不会今天还在。稀有果的 3 日周期刚好等于一次远征的往返成本。

## 2. 失活（Spoilage）

果实从采摘那一刻开始倒计时。

```
  采摘 ──fresh 倒计时──→ fresh ≤ 0 ──→ 变成「果核」(kind:'pit')
                                          │
                                          ├─ 不能吃（无变形效果）
                                          ├─ 占 ceil(slots/2) 格（减半）
                                          └─ 可种 → 若干天后长成果实树
```

- 背包内衰减速率 ×1.0；主果窖 ×0.1；窖树 ×0.33（见 05）。
- 失活时游戏会明确通知：「猫头鹰果 失活了，只剩一颗果核——种下去也许还能结果。」
- **没有"保鲜"道具**。唯一的减速手段是仓库。

## 4. 形态能力字段

| 字段 | 含义 | 玩家感知 |
|---|---|---|
| `size[w,h]` | 碰撞盒（米） | 能进多矮的洞；决定能否通过 1×1 通道 |
| `speed` | 陆地速度倍率 | 狐狸 1.45 / 独角兽 2.1 / 水母 0.5 |
| `jump` | 跳跃力倍率 | 鹿 1.5 / 独角兽 1.6 |
| `swim` | 水中速度倍率 | 人鱼 2.6 / 水獭 2.2 |
| `fly` | 飞行推力（0 = 不能飞） | 猫头鹰 5.2 / 龙 9.0 |
| `glide` | 无动力滑翔（下落上限） | 蝙蝠 0.25 = 几乎不坠 |
| `breatheAir:false` | 水下呼吸 | 只有人鱼 |
| `airBonus` | 额外闭气秒数 | 水獭 +25 / 水母 +40 |
| `nightVision` | 暗处提亮 0–1 | 蝙蝠 0.95 |
| `glow[r,g,b]` | 自身发光 | 萤蛾、水母、独角兽、凤凰、龙 |
| `stealth` | 生物警觉半径倍率 | 灰雾兽 0.15 = 几乎不被发现 |
| `aura` | 威吓半径 | 龙 18 = 所到之处生物逃散 |
| `climb` | 爬墙 | 只有巨蛛 |
| `dig` | 破坏软质方块 | 只有狐狸 |
| `fire` | 喷火 / 免疫火 | 凤凰、龙 |
| `purify` | 净化毒水 | 独角兽 |
| `talk` | 与某类生物交流 | 人鱼 `water`、独角兽 `beast` |
| `step` | 自动登阶高度（米） | 龙 1.6 = 走上一切台阶 |
| `fov` | 视野角 | 巨蛛 110 / 鹿 70 |
| `hand` | 第一人称手部模型 | talon/wing/paw/hoof/fin/claw/tentacle/shadow |

**注意 `size` 是硬门禁**：狐狸 0.55×0.6 能过 1×1 的根洞；雄鹿 0.9×1.6 不能——这就是"角会卡在门框"这条副作用的物理实现，不是纯文本。

## 5. 变形规则

### 5.1 时间条

- 吃下后开始倒计时，HUD 底部显示形态名 + 剩余时间。
- 时间到 → 复原为人形，播报副作用的"余韵"。
- 主动复原：按 `R`（提前结束，不返还时间）。

### 5.2 魔力胃（原型：覆盖 + 警告）

- 已有形态时再吃第二颗 → 第二颗覆盖第一颗，并造成 **1.5 点活力伤害** + 「魔力胃翻搅——两种魔法在体内打架！」
- 正式设计（未实现）：
  - 两种形态的"魔法残留"在胃里共存 90 秒，期间所有动作判定 −30%。
  - 若两种形态体型差 ≥ 1.0 m，翻搅伤害翻倍（人 → 龙 → 水母 是最危险的组合）。
  - **林奈的例外**：她能主动"混胃"，见 5.3。

### 5.3 混合形态（未实现，正式设计）

同时吃下两种果且**不翻搅**（需要"魔力胃"天赋或特定植物中和），得到半程混合形态：

| 组合 | 混合形态 | 时长 | 特性 |
|---|---|---|---|
| 猫头鹰 + 蝙蝠 | 夜翼 | 150 s | 夜视 1.0，fly 5.8，但白昼完全致盲 |
| 水獭 + 人鱼 | 半潮 | 400 s | 水陆两全，但离水时间条 1.5 倍 |
| 狐狸 + 巨蛛 | 巢行者 | 300 s | climb + dig，村民永久拒交易 |
| 独角兽 + 龙 | **角与灰** | 180 s | 全能力，但灰雾墙永久标记你（进入灰雾即受伤） |

混合形态的果实占用 = 两者之和（12+4=16 格），这是"想混就得清空背包"的代价。

### 5.4 兽化残留（未实现，正式设计）

同一形态反复变形会在人形上留下痕迹：

| 累计变形次数 | 残留 |
|---|---|
| 5 | 夜视 +0.15（猫头鹰/蝙蝠系） |
| 10 | 该种生物对你的警觉 −20% |
| 20 | 图鉴里该种生物的文案会多出一行"它认得你" |
| 30 | **不可逆**：人形 `size` 永久 +0.1 m（进某些洞变难） |

设计意图：让"变形"不是零成本的工具，而是一种**身份漂移**。

## 6. 空果（主线机制）

某些果实树结的是**空果**：外观、占格、失活完全相同，吃下无任何效果，只播报「这个果子没有味道。」

- 空果是母树失忆的表征，随主线推进增多。
- 空果**仍然能种**，且种下后长成的树有 15% 概率恢复为实果——这是玩家对抗世界衰退的唯一手段。
- 图鉴中空果显示为"？"，不占用图鉴完成度。

## 7. 采摘交互

| 步骤 | 表现 |
|---|---|
| 准星对准果实方块 | 高亮 + 提示「E — 采集 猫头鹰果（常见，占 1 果格）」 |
| 按 E | 果实方块消失，背包 +1，播报稀有度与占格 |
| 背包满 | 「背包满了（24/24 果格）——先回果窖。」果实**不掉**，留在原地 |
| 果实方块 | 微自发光小盒（0.44³ 主体 + 两片小叶），颜色 = 稀有度环色 |

果实方块 id 40–54（15 种），非固体、非不透明、`emis:1`——夜里靠它自己发光才能被看见。这是"夜里能看见猫头鹰果微微反光"的实现。
