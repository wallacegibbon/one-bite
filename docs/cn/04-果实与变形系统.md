# 04 · 果实与变形系统

[English: ../en/04-fruit-and-transformation.md](../en/04-fruit-and-transformation.md)

数据真源：`game/data/fruits.js`。文档中的每个数字都直接来自该文件。

**一种动物一种果。** 谷地有四种能穿的动物（03），所以有四种变形果。没有"第二种狐狸果"，也没有不属于任何动物的果。

## 1. 稀有度：容量与保质期

稀有度不是"价值等级"，是**两个物理参数**：

| 稀有度 | 中文 | 占果格 | 失活时间 | 重新结果 | 环色 |
|---|---|---|---|---|---|
| common | 常见 | **1** | 1500 s（25 分） | 1.0 游戏日 | `#9ab97e` |
| uncommon | 少见 | **2** | 1200 s（20 分） | 1.5 游戏日 | `#6cb4f0` |
| rare | 稀有 | **4** | 900 s（15 分） | 2.0 游戏日 | `#b987f2` |
| epic | 极稀 | **7** | 600 s（10 分） | 2.5 游戏日 | `#ff9c4a` |
| legendary | 传说 | **12** | 420 s（7 分） | 3.0 游戏日 | `#ffdc5c` |

**背包 24 格** → 一次最多装：24 常见 / 12 少见 / 6 稀有 / 3 极稀 / **2 传说**。

谷地现在只长这五级里的**三级**——常见、稀有、传说。梯子留着：它是储存的法则，不是购物清单。

一条关键推论：一颗棕熊果（12 格）+ 一颗蛙果（4 格）= 24 格里用掉 16 格，**只剩 8 格带别的**。这就是"把谷地最重的身体和湖那具身体一起背上"的物理代价：你到了北岭，而且没有余量带第二颗——两颗棕熊果正好把背包填满，里面装不下任何东西。

### 1.1 重新结果（Regrow）

摘掉的果实方块不会永久消失——果木的根系会把养分重新送回去。所需时间按稀有度排（见上表），实际值在 ±20% 内随机，避免同一批果实同时成熟。规则：

- 只有**果实方块**会重生；蘑菇、发光种子等植物不重生（否则窖树种可无限刷）。
- 重生计时在**存档里保存**，退出游戏期间不推进——谷地不等你。
- 若原位置已被别的方块占住（玩家砍了树、熊撞塌了枝），这次重生**作废**，不硬塞。
- 设计意图：谷地不会被掏空，但"昨天那棵"不会今天还在。传说果的 3 日周期刚好等于一次远征的往返成本。

## 2. 失活（Spoilage）

果实从采摘那一刻开始倒计时。

```
  采摘 ──fresh 倒计时──→ fresh ≤ 0 ──→ 变成「果核」(kind:'pit')
                                          │
                                          ├─ 不能吃（无变形效果）
                                          ├─ 占 ceil(slots/2) 格（减半）
                                          └─ 可种 → 若干天后长成果实树
```

- 背包内衰减速率 ×1.0；主果窖 ×0.1；窖树 ×0.33（见 05）。
- 失活时游戏会明确通知：「猫头鹰果 失活了，只剩一颗果核——种下去也许还能结果。」
- **没有"保鲜"道具**。唯一的减速手段是仓库。

| id | 中文 | 形态 | 时长 | 栖息 | 关键能力 | 代价（只在身体） |

**这张表里的副作用，原型真正执行的是雨蛙的皮肤、猫头鹰的白昼和北岭的冷**：`dryTimer` 让雨蛙形离水 90 秒后活力开始下降；`nightVision` 让有这双眼睛的身体在暗处看得更清，同这双眼睛在白昼被晃白；北岭的冷在 y26 以上收取活力，而棕熊形永远感觉不到。仍然只写在纸面上的：爪与掌"不能开仓库"（现在哪具身体都开得开）、雨蛙"够不到高处的果"（所有身体的采摘距离是同一个定值）、薄冰不会裂、木桥不会塌。"关键能力"那一列里的每一项现在都有代码在读——见 §4。

**为什么没有第五种**：果实表就是动物表的镜像。加一种果等于加一个生态位、加一行态度矩阵、加一套门禁（03 §3）。四种是"十秒能读完"的量；第五种得先把这个位置挣回来。

## 4. 形态能力字段

最后一列写的是原型的现状，不是目标。`game/test/reach.js` 会去读数据文件和代码，
每次运行都把这条分界线打印出来——所以一个字段不可能挂在这张表里看起来像是实现了，
实际上却没有任何代码读它。

| 字段 | 含义 | 玩家感知 | 原型 |
|---|---|---|---|
| `size[w,h]` | 碰撞盒（米） | 能进多矮的洞；决定能否通过 1×1 通道 | 已实现 |
| `speed` | 陆地速度倍率 | 棕熊 1.1 / 雨蛙 0.9 | 已实现 |
| `jump` | 跳跃力倍率 | 雨蛙 1.3 / 棕熊 0.9 | 已实现 |
| `hop {up,kick,period}` | 这具身体在陆地上不走，它跳：自动跳占它自身跳跃的比例、起跳把它抛出去的速度是陆地速度的几倍、两次起跳之间脚在地上停几秒 | 只有雨蛙：大约每秒一次 1.4 米的弧线，地面速度和人形一样 | 已实现 |
| `swim` | 水中速度倍率 | 雨蛙 2.4 | 已实现 |
| `fly` | 飞行推力（0 = 不能飞） | 只有猫头鹰 5.2 | 已实现 |
| `glide` | 无动力滑翔：下落速度上限，按正常下落速度的比例 | 猫头鹰 0.35——松开按键猫头鹰就不会悬在空气里，它以你三分之一的速度往下掉，同时保住原有的水平速度 | 已实现 |
| `breatheAir:false` | 水下呼吸 | 只有雨蛙 | 已实现 |
| `dryTimer` | 离水后皮肤开始干燥的秒数（两栖身体） | 只有雨蛙 90 | 已实现 |
| `nightVision` | 暗处提亮 0–1，同一双眼睛在白昼被晃白 | 猫头鹰 0.75 / 雨蛙 0.3 | 已实现 |
| `stealth` | 生物警觉半径倍率 | 猫头鹰 0.45 / 雨蛙 0.5 = 很难被发现 | 已实现 |
| `aura` | 威吓半径 | 棕熊 8 = 走近时小动物先散 | 已实现 |
| `coldImmune` | 北岭的高海拔寒冷咬不动 | 棕熊 | 已实现 |
| `step` | 自动登阶高度（米） | 棕熊 1.1 = 走上一切台阶 | 已实现 |
| `fov` | 视野角 | 雨蛙 100 / 棕熊 68 | 已实现 |
| `hand` | 第一人称手部模型 | hand/talon/web/claw | 已实现 |

其中一个是开关而不是数值：`coldImmune` 改变的是"什么东西根本伤不到你"，而不是"伤多少"。它也正好是谷地文案喊得最响的一个：北岭的文案说棕熊身体不怕冷。这条现在是代码在跑规则。

`tongue` 以前在这张表上（雨蛙，采摘伸出 4 米）。它被删了：雨蛙的生态位是游泳和水下呼吸，而多一条"够得到东西"的途径，会让体型这道门——雨蛙钻得过的 1×1 缺口棕熊钻不过——从唯一的门变成几扇门之一。

三具身体上一共十七个能力字段，全部有代码在读。`game/test/reach.js` 每次运行都重新问一遍这个问题，只要数据里加了字段而 `game/src/` 里没人读它就报错，所以这一列不可能悄悄烂回广告。

**注意 `size` 是硬门禁**：雨蛙 0.5×0.5 能过 1×1 的根洞与芦苇缝；棕熊 1.4×1.5 不能——这就是"体重压塌木桥""这具身体进不了那道门"这类副作用的物理实现，不是纯文本。

同一个盒子也是**画出来的身体**要装进去的那个框。`game/test/node-smoke.js` 会把每个模型按它所属生物的碰撞盒量一遍，模型超出就失败（为什么量的是半径而不是宽度，07 §1 有解释）：身体比碰撞盒宽，就会被自己看得见、却碰不到的几何体穿过去。

## 5. 变形规则

### 5.0 继承规则：全部能力，全部脆弱

变形不是穿一件装备，是换一具身体。**你继承你变成的动物的所有能力和所有缺点**——它的强大全部归你，它的脆弱也全部归你。

代价只有两种来源：

| 来源 | 例子 | 为什么 |
|---|---|---|
| **这具身体做不到** | 爪与嘴无法精细操作（不能采小果、不能开仓库）；1.4×1.5 的身体进不了低矮与狭窄处；体重压塌薄冰与木桥；离水 90 秒后皮肤脱水；白昼畏光 | 身体换了，能力表就换了 |
| **世界对这具身体的反应** | 猫头鹰见你走近就飞开——人形飞开，变成棕熊形飞得更快；湖岸的蛙不理人形、见了猫头鹰形就逃、而你穿着它们自己那具身体时一动不动 | 它们不认识"你"，只认识这具身体 |

**脑子不受影响。** 变形不会让你想做任何事，也不会让你不能做任何事。你在棕熊的身体里还是你：想什么、怕什么、决定什么，都和人形时一样。

唯一的例外是**身体反射**：这具身体会在你决定之前先惊跳（`fright`）——有东西撞进来时那一下抖会烧掉氧气、加快时间条。这是生理，不是心理：那一下抖你控制不了，但接下来怎么办仍然由你决定。

### 5.1 时间条

- 吃下后开始倒计时，HUD 底部显示形态名 + 剩余时间。
- 时间到 → 复原为人形。
- 主动复原：按 `R`（提前结束，不返还时间）。
- **已有形态时再吃一颗，就直接变成那一种。** 你当时那具身体立刻结束，吃下的那颗照它写的效果生效。没有一个器官装着两种魔法，没有"已经吞了几颗"的计数，吃它们的顺序也没有惩罚。代价就是你提前结束的那具身体和你花掉的那颗果子——P3 已经替你算过这个价。

**一次只有一种身体。** 这是世界的法则，不是难度设定。任何天赋、植物或道具都不能让两种身体共存。一旦一个背包能装下两种身体，谷地里的每道门就不再是"我要带着哪种身体到门前"的决定，而变成一张购物清单。

## 6. 采摘交互

| 步骤 | 表现 |
|---|---|
| 准星对准果实方块 | 高亮 + 提示「E — 采集 猫头鹰果（常见，占 1 果格）」 |
| 按 E | 果实方块消失，背包 +1，播报稀有度与占格 |
| 背包满 | 「背包满了（24/24 果格）——先回果窖。」果实**不掉**，留在原地 |
| 果实方块 | 微自发光小盒（0.44³ 主体 + 两片小叶），颜色 = 稀有度环色 |

果实方块 id 40–42（3 种），非固体、非不透明、`emis:1`——夜里靠它自己发光才能被看见。这是"夜里能看见猫头鹰果微微反光"的实现。
