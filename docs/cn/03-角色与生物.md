# 03 · 角色与生物

[English: ../en/03-characters-and-creatures.md](../en/03-characters-and-creatures.md)

数据真源：`game/data/creatures.js`（14 种生物 + 态度矩阵 + 图鉴文案）、`game/data/player.js`（身份层：编号 / 称呼 / 名字）。

## 1. 主角

### 采集者（16 岁）—— 名字由玩家决定

灯笼镇外的采集者学徒。**这个角色没有固定名字**：谷地不用名字称呼人，只按"你做过什么"给你称呼（见 §6）。文档里提到这个角色时一律用"采集者"或第二人称。

- **动机**：进谷地时带着一张手绘的果实表。表上有 41 种果，谷地里现在只找得到 15 种。想知道另外 26 种是没了，还是记错了。
- **天赋 `混胃`**：能同时压住两种魔法。普通人吃下两种果会魔力胃翻搅致死，你只是难受。这是"魔力胃"规则的例外，也是终章嫁接路线的前提。**注意它是角色的属性，不是世界的法则**——多人时它是稀有的，不能假定某个玩家一定有（见 §6）。
- **背景槽位**：那张表是谁留下的，属于角色的背景，不是世界的设定。单人时是"祖母"；多人时每个角色可以有不同的来源（同门、债主、灰手套的旧雇员），或者表根本由老梅代管、角色只是认得它。
- **不说的话**：表的原主人是被灰手套商会赶出谷地的。

### 老梅（Old Mei，约 70 岁）

主果窖的看守。灯笼镇果窖的形制是她定的：96 格、地下、恒温、腐坏速度 ×0.1。

- 她**从不吃果实**。整个游戏里她一次都没变过形。问她，她说："我闻过一颗焰心果。够了。"
- 功能：教学、背包升级（副果袋 +6 格）、窖树种子的唯一来源。
- 秘密：她能闻出果实的剩余新鲜度——精确到分钟。这就是为什么果窖从不失活堆积。

### 托班·奎尔（Toban Quill）

灰手套商会的谷地代理。三十多岁，手套是灰的，因为"手上不能留果渍"。

- 他不邪恶。他的立场是：谷地的果实能治外面的病，而谷地只有九公里宽。
- 他做三件事：收购果实（给钱，钱在谷地没用）、在果园遗迹布捕果夹（block 80）、试图带一颗焰心果穿过灰雾墙。
- 玩家对他的正确用法：**他不知道哪种果会失活**。从他手里换到的稀有果往往只剩一半时间。

### 白露 / 钟摆 / 珊瑚舌 / 灰烬（具名生物）

| 名 | 种 | 位置 | 作用 |
|---|---|---|---|
| **白露** | 独角兽 | 圣林之心 | 唯一认得当年那张果实表的独角兽。它顶穿过奎尔两次 |
| **钟摆** | 猫头鹰 | 星坠堡钟塔 | 义务巡逻队的头。会替玩家把掉在远处的果实叼回最近的仓库（每 3 天 1 次） |
| **珊瑚舌** | 人鱼 | 人鱼村 | "归还"谈判者。要回沉塔里的一只铜铃 |
| **灰烬** | 灰鳞龙 | 云顶龙巢 | 全谷地唯一愿意落地的龙——因为它快死了。终章三条路线都要它 |

## 2. 生物态度系统

态度不是数值好感，是**"你现在的形状是什么"**的查表结果。

| 态度 | 行为 |
|---|---|
| `calm` | 无视，同群 |
| `ignore` | 不主动反应，被靠近才逃 |
| `curious` | 靠近观察（可能引导玩家去某处） |
| `flee` | 在 `alert` 半径内逃跑 |
| `hostile` | 在 `alert` 半径内冲锋/攻击 |

查表顺序：`attitude[玩家当前形态的 creature id]` → `attitude.human`（人形时）→ `attitude.default`。

**读矩阵的三条设计意图**：

1. **对角线全是 `calm`** —— 变成该种就是通行证。圣林、龙巢、人鱼村都靠这条。
2. **独角兽那一行几乎全 hostile** —— 独角兽不是和平生物，它是"伪装检测器"。任何非独角兽形状进入圣林都会被顶。
3. **龙那一行对龙 hostile** —— 焰心果路线上，吃下焰心果变成龙并不安全：其他龙会攻击你。这是传说级果实必须带副作用的证明。

## 4. 图鉴文案（游戏内已实现）

每种生物一段，写法固定为「可验证事实 + 不可验证传闻」：

- **猫头鹰**：白天塞在树洞里，像一截会呼吸的木头。夜里它是整片林子的耳朵。谷地里的猫头鹰不抓老鼠——它们抓"失窃的果实"，是灯笼镇义务巡逻队。
- **蝙蝠**：它们用"合唱"定位：一整洞蝙蝠同时发声，把隧道画成一张声音的地图。变成蝙蝠后你会不由自主地加入合唱。
- **萤蛾**：发光种子开出的蛾。它们会排成一条线，指向最近的水源——老采果人管这叫"蛾路"，是迷路时最可靠的指南针。
- **水獭**：会把石头藏在腋下睡觉。它们偷人鱼村的贝壳，人鱼睁一只眼闭一只眼——因为水獭会替人鱼把沉船里的东西搬上来。
- **赤狐**：灯笼镇的鸡舍从来不上锁，因为狐狸只偷"掉在地上的"。镇民因此认定狐狸是诚实的——这条法律已经三百年没被推翻。
- **白尾鹿**：鹿径不是路，是几百年里被同一群鹿踩出来的"决定"。跟着鹿径走一定能找到水，也一定能找到狼。
- **灯水母**：镜湖的灯。水母田的位置就是湖底沉塔的轮廓——从水面看下去，塔在发光。
- **人鱼**：人鱼不数人头，数"归还"。你每还一样湖中之物，它们就给你一件。你每拿走一样，湖就记住你一次。
- **独角兽**：它不容冒犯——任何不是独角兽的东西踏进圣林，都会被顶出去。所以圣林唯一的通行证，是真的变成独角兽。
- **梁蛛**：住在梁上，不结网捕虫，结网"补房子"。果园遗迹至今没塌，靠的是它们三百年织的梁。
- **灰熊**：北岭的熊会挖"果窖"——它们比人类更早学会把果实埋起来慢慢吃。灯笼镇的果窖形制，据说是抄熊的。
- **灰鳞龙**：谷地里只登记过三只成年灰鳞龙。它们不落地，只在云顶绕圈——落地的龙，说明它已经不行了。
- **灰雾兽**：它们不咬人，只"拿走"。被灰雾兽碰过的背包格会空一颗，而且你想不起来那颗是什么。
- **灰烬凤凰**：黄昏时才会被看见。它每次落地都会烧掉一小片云，所以云顶永远有新鲜的灰。

## 6. 身份与命名（为多人准备）

**主角的名字不是设定的一部分。** 数据真源是 `game/data/player.js` 里的 `IDENTITY`。

身份分三层，其中只有第一层能活到多人：

| 层 | 字段 | 谁决定 | 可变 | 唯一 | 说明 |
|---|---|---|---|---|---|
| 编号 | `id` | 系统 | 否 | 是 | 前缀 `p-`，随机 idBytes 6 位。世界只记这个：窖树归属、猫头鹰邮递、湖的账、兽化残留 |
| 称呼 | `epithet` | 世界（按你做过什么） | 会变 | 不保证 | 文案只用它。默认「数果子的」，做完事会升级 |
| 名字 | `name` | 玩家（按 N） | 是 | 否 | 上限 nameMax 16 字。留空也完全可以 |

### 为什么世界观本身就要求这样

灰雾墙最先带走的就是名字——它让你忘记"为什么要回来"，而名字正是"回来"的锚。所以谷地的所有机构都不靠名字运作：果窖按形状和作为记账，义务巡逻队按称呼认人，人鱼数"归还"不数人头。**"不用名字"是世界观的推论，不是为多人做的妥协。**

### 写作规则（可被测试）

1. **任何文案不得插值玩家名字。** 用称呼，或用第二人称。`docs-sync.js` 会在文档里出现固定主角名时失败。
2. 名字只出现在 UI（HUD 左上角、图鉴"你"页），不出现在 NPC 台词、图鉴条目、任务文本里。
3. 称呼是**世界的评价**，所以它可以是贬义的（「假独角兽」）——玩家改名改变不了世界怎么看你。

### 多人：已经落地的 / 还差的

**已落地**：`id` 进存档、窖树带 `owner`、称呼由事件驱动、名字与身份解耦、`混胃` 是角色天赋而非世界法则。

**还差**：身份服务（`id` 由服务器签发）、仓库归属与共享权限（主果窖目前是公用的）、人鱼的"账"按 id 记、兽化残留按角色累计、NPC 按 id 记忆对话、以及"两个玩家同时变成独角兽走进圣林"这类态度矩阵冲突的解法。
