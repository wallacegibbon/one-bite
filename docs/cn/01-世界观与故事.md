# 01 · 世界观与故事

[English: ../en/01-worldview-and-story.md](../en/01-worldview-and-story.md)

## 1. 果灵谷（Frutaria）

一片被**灰雾墙**完整包围的盆地，直径约九公里。盆地内部有森林、一个极深的湖、一条北岭、一片果园遗迹，以及一串**悬浮在空中的岩岛**。

谷地只有一个物理特征值得记住：**这里的一切植物都倾向于结果，而一切果实都倾向于记得动物。**

同一株植物不会结两种果。一株树如果结出猫头鹰果，说明它百年内被猫头鹰反复吃过、埋过、忘过。果实是植物的记忆，不是植物的器官。

### 灰雾墙（The Grey Veil）

环绕谷地的灰色雾带，厚约 400 米，高不见顶。

- 它**不阻止**你走出去。可以走进去，能穿过去，另一侧是普通的山坡。
- 它阻止的是**回来**。走出去的人会在两小时内忘记自己为什么要回来；带出去的果实会在一天内变成普通水果（失去所有魔法）。
- 灰雾里唯一会结果的东西是**灰雾果**——它不是植物，是某种动物的遗愿结成的核。
- 灰雾兽生活在雾里。它们不咬人，只"拿走"：被碰过的背包格会空一颗，而且你想不起来那颗是什么。

> 设计用途：世界边界不用墙，用**遗忘**。玩家不会撞墙，只会回头——因为再往前就没有理由了。

## 2. 食形术：为什么没有魔杖

谷地外的巫师用魔杖。魔杖的原理是**把手指指向哪里，力量就去哪里**——它是一条方向性的、外置的工具。

果灵谷里没有这种东西。原因在**母树**。

### 母树（Mother Bloom）

果园遗迹中央那株枯了一半的巨树。所有果实树都是它的根系延伸；所有果实都是它的记忆碎片。母树的根系覆盖了整个谷地的地下，它做了一件魔杖永远做不到的事：

**它把动物的记忆种进了植物。**

因此谷地的魔法是**内向的**：你不能把力量指出去，只能把别的东西收进来。指、挥、念这些动作在这里没有意义——事实上，历史上有人带魔杖进谷，魔杖在谷内会持续"指向"母树方向，像一根永远偏的罗盘，最后自己裂开。

> 星坠堡的院训：**"这里不用魔杖——这里连'指'的动作都没有。"**

### 代价：魔力胃

人的胃不能同时处理两种魔法。连续吃下两种果实会**翻搅**：活力下降、时间条重置、当前形态被覆盖。老练的采集者会"排空"——等形态结束、胃里干净，再吃下一颗。

（原型已实现"覆盖 + 翻搅警告"；完整的魔力胃规则见 04。）

## 3. 母树的失忆（主线谜团）

母树正在失忆。

它每失忆一次，谷地里就有一整类果实**不再结果**——树还活着，果子还是那个形状，但吃下去什么都不会发生。玩家在游戏第一幕就会遇到这种情况：低语林里有几株猫头鹰果树结出的果是"空"的。

失忆的原因（第三幕揭示）：

**灰雾墙就是母树。**

母树在几百年前为了不被砍伐，把自己的一部分长成了包围谷地的雾。雾是它的身体，谷地是它的果实。它开始遗忘，是因为**它记得的东西太多，而带出去的东西都不回来**。

于是主线真正的选择是：

| 结局路线 | 做法 | 代价 |
|---|---|---|
| **归还** | 把母树花蕾（母树果）种回果园遗迹，让所有被带走的记忆回流 | 谷地内所有魔法果实永久失去一半效力；玩家永远无法再变成龙 |
| **嫁接** | 把焰心果（龙）与母树花蕾嫁接，造出一株新的记忆树 | 母树彻底死亡；谷地魔法转移到云顶浮岛，从此所有稀有果都在天上，代价是必须飞行才能采集 |
| **不干预** | 什么都不做 | 谷地逐年"变普通"；图鉴里会出现越来越多的空果 |

## 4. 时间线

| 年 | 事件 |
|---|---|
| 约 900 年前 | 母树存在的最早记录。山谷里的居民发现吃果能变形 |
| 约 600 年前 | **第一次灰雾**。母树长成雾墙，围住谷地。外面的人称此地"消失" |
| 约 400 年前 | 星坠堡建立。它不是魔法学院，是**果窖与认果学校** |
| 约 300 年前 | 灯笼镇形成。镇规第一条：果实不入屋，只入窖 |
| 约 300 年前 | 果园遗迹荒废。母树第一次大规模失忆，一夜之间 40 种果变空 |
| 约 120 年前 | 灰手套商会成立。开始系统性外运果实——第一次"果实外流" |
| 30 年前 | **北岭之冬**。灰熊绝迹一年，因为灰熊埋的果窖全部失活 |
| 今年 | 游戏开始。一名 16 岁的采集者第一次进入谷地 |

## 5. 主线七章（详见 06）

1. **空果** — 低语林的猫头鹰果是空的。为什么？
2. **认果** — 星坠堡温室，学会分辨稀有度与失活。
3. **湖的账** — 人鱼要求归还一件湖中之物。
4. **圣林的形状** — 独角兽只攻击"伪装成独角兽的人"。
5. **灰手套** — 商会在把果实运出灰雾墙。
6. **云顶** — 灰烬龙巢，焰心果。
7. **母树** — 三个结局。

## 6. 语气与文体

- 世界不解释自己。所有设定都通过**果实描述**、**图鉴条目**、**镇规**、**任务失败提示**传达。
- 图鉴文案的写法：先给一个可验证的事实，再给一句无法验证的传闻。
  > 例：「灰紫色的小果，长在老橡树洞里，只在夜里能看见它微微反光。守夜人说：'摘猫头鹰果最好的办法，是先变成猫头鹰。'」
- 禁止出现的词：魔力值、等级、经验、任务奖励、升级。
- 幽默是干燥的、行政式的：
  > 「窖树最多 3 棵——谷地记不住更多地方。」
