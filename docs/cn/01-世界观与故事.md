# 01 · 这个世界

[English: ../en/01-worldview-and-story.md](../en/01-worldview-and-story.md)

## 1. 果灵谷（Frutaria）

一片被**灰雾**完整包围的盆地，直径约九公里。里面有森林、一个极深的湖、一条北岭、一片果园遗迹，以及一串**悬浮在空中的岩岛**。

这个世界只有三样东西：

| | |
|---|---|
| **人** | 谷地里有镇子、有果园、有仓库。人不做特别的事，人采摘、储藏、交易 |
| **动物** | 每种动物住在自己的地盘上，有自己的能力和自己的脆弱 |
| **魔法果实** | 每只动物在自己的地盘上结出自己的果。同一株植物不会结两种果 |

**唯一的魔法：吃下果实，你变成果实记得的那只动物；一段时间后变回来。**

没有别的魔法。没有咒语，没有手势，没有法器，没有职业，没有等级，没有神明，没有预言。

> 设计用途：设定越少，玩家的注意力就越完整地落在**身体、地形、时间**这三件事上。

## 2. 玩家的目标：生存，然后体验

这个世界没有要解开的谜，没有要救的人，没有反派。你在这里做两件事。

| 生存 | 体验 |
|---|---|
| 果实会腐坏，背包只有 24 格，而谷地比一颗果实的寿命大——所以你要安排、要储藏、要取舍 | 变成猫头鹰飞过一次夜林，变成雨蛙沉到镜湖底，变成棕熊撞开一条路：每种身体都给你一片平时看不到的谷地 |

失败也很简单：溺水、北岭的冷、被水母蜇、蛙形在岸上脱水、边界上的灰雾，还有时间到。没有失败剧情，死了就在镇子里醒来，背包里的东西掉在你倒下的地方。

## 3. 灰雾（世界边界）

环绕谷地的灰色雾带，厚约 400 米，高不见顶。

- 它**不阻止**你走出去。可以走进去，能穿过去，另一侧是普通的山坡。
- 它阻止的是**回来**。走出去的人会在两小时内忘记自己为什么要回来；带出去的果实会在一天内变成普通水果，失去所有魔法。
- 雾里很冷，越往里越难走。**雾里没有动物**——一个活物都没有，这是最让人不安的地方。

> 设计用途：世界边界不用墙，用**遗忘**。玩家不会撞墙，只会自己掉头——因为再往前就没有理由了。

## 4. 变形怎么工作（详见 04）

- 吃下果实 → 变成它记得的动物 → 时间条走完 → 变回人形。
- **你继承那具身体的全部**：它能做的一切，也做不到的一切。爪子开不了仓库，角进不了窄洞，离水的皮肤会干裂。**脑子不受影响**——你在棕熊的身体里还是你（04 §5.0）。
- **一次只有一种身体。** 还在形态里时吃下第二颗，就直接换成那一种身体——你当时那具身体立刻结束。没有惩罚，也没有装着两种魔法的器官；代价是你提前结束的那具身体和你花掉的那颗果子（04 §5.1）。
- 果实离开身体就开始腐坏。失活的果实变成果核，果核能种下去——一百多年后，这里也许会长出一株新的果木。

## 5. 语气与文体

- 世界不解释自己。所有设定都通过**果实描述**、**图鉴条目**、**镇规**、**任务失败提示**传达。
- 图鉴文案的写法：先给一个可验证的事实，再给一句无法验证的传闻。
  > 例：「灰紫色的小果，长在老橡树洞里，只在夜里能看见它微微反光。守夜人说：'摘猫头鹰果最好的办法，是先变成猫头鹰。'」
- 禁止出现的词：魔力值、等级、经验、任务奖励、升级。
- 幽默是干燥的、行政式的：
  > 「窖树最多 3 棵——谷地记不住更多地方。」
