# 万灵果园 · FRUTARIA

**中文** · [English: ../en/README.md](../en/README.md)

> 一个只有一种魔法的世界，那种魔法是果实。魔法不在手上，在嘴里。

一个体素（voxel）风格的开放探索游戏设计文档集 + 可玩原型。

## 一句话

你是一名**十六岁的采集者**（名字由你自己定，谷地不用名字称呼人），第一次走进**果灵谷**。这里只有一种魔法：**吃下果实，变成果实所记得的动物**，一段时间后再变回来——你会完整继承那具身体的能力与脆弱，而脑子仍然属于你。谷地被一圈**灰雾**围住，里面有森林、湖、山和浮岛，每种动物住在自己的地盘上（名单见 03）。每种动物都在自己的地盘上结出自己的果。你的背包只有 **24 个果格**，而越珍贵的果实越大颗——**你不可能把所有魔法都带在身上**。

## 核心循环

```
        ┌──────────────────────────────────────────────────┐
        │                                                  │
   探索地形 → 发现果实 → 采摘（占果格、开始腐坏）→ 变形 → 用新身体进入新地形
        │                                                  │
        └──── 回果窖存放 / 种下果核 / 解锁更远的区域 ←──────┘
```

三条互相咬合的张力：

| 张力 | 机制 |
|---|---|
| **背包装不下** | 果实按稀有度占 1/2/4/7/12 格，背包 24 格 → 一次最多 2 颗传说果 |
| **果实会失活** | 采摘后开始倒计时（常见 25 分 → 传说 7 分），失活变果核 |
| **继承全部** | 变形是继承：你得到那只动物能做的一切，也得到它做不到的一切（爪开不了仓库、角进不了窄洞、离水会干裂…）。脑子不受影响——想做什么，仍然是你决定 |

## 原型

`game/index.html` — 零依赖自研 WebGL1 体素渲染器，直接双击打开即可（或 `python3 -m http.server` 后访问 `/game/`）。

原型已实现：地形生成（城堡/镇/湖/洞/浮岛）、3 种生物 AI（态度驱动）、3 种果实、变形与能力切换、24 果格背包与腐坏、主果窖 + 窖树仓库、6 条任务、图鉴、日夜、灰雾墙边界、死亡掉落与捡回、身份层（编号 / 称呼 / 名字，主角无固定名字）、界面语言可切换（中 / EN，见 07 §3.4）、localStorage 存档。
原型未实现（文档中已设计）：NPC 对话树、窖树被棕熊拆毁的判定、雨蛙形的皮肤湿度条、程序化音频。

## 数据即设定

`game/data/fruits.js`、`game/data/creatures.js`、`game/data/world.js`、`game/data/player.js` 是**唯一的设定真源**：文档里的每个数字（果格数、失活时间、态度、区域半径、称呼表）都来自这四个文件。改设定改数据，文档随之重生成。
