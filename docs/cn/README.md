# 万灵果园 · FRUTARIA

**中文** · [English: ../en/README.md](../en/README.md)

> 一个没有魔杖的魔法世界。魔法不在手上，在嘴里。

一个体素（voxel）风格的开放探索游戏设计文档集 + 可玩原型。

## 一句话

你叫**林奈**，十六岁，第一次走进**果灵谷**。这里的巫师不用魔杖——他们**吃下果实，变成果实所记得的动物**，一段时间后再变回来。谷地被一圈**灰雾墙**围住，里面有森林、湖、山和浮岛，住着猫头鹰、蝙蝠、水獭、狐狸、鹿、水母、人鱼、独角兽、巨蛛、灰熊、灰雾兽、凤凰和龙。每种动物都在自己的地盘上结出自己的果。你的背包只有 **24 个果格**，而越珍贵的果实越大颗——**你不可能把所有魔法都带在身上**。

## 核心循环

```
        ┌──────────────────────────────────────────────────┐
        │                                                  │
   探索地形 → 发现果实 → 采摘（占果格、开始腐坏）→ 变形 → 用新身体进入新地形
        │                                                  │
        └──── 回果窖存放 / 种下果核 / 解锁更远的区域 ←──────┘
```

三条互相咬合的张力：

| 张力 | 机制 |
|---|---|
| **背包装不下** | 果实按稀有度占 1/2/4/7/12 格，背包 24 格 → 一次最多 2 颗传说果 |
| **果实会失活** | 采摘后开始倒计时（常见 25 分 → 传说 7 分），失活变果核 |
| **身体会拒绝** | 每种形态有副作用（畏光、趋光、偷窃冲动、无法说谎…），变形不是纯增益 |

## 原型

`game/index.html` — 零依赖自研 WebGL1 体素渲染器，直接双击打开即可（或 `python3 -m http.server` 后访问 `/game/`）。

原型已实现：地形生成（城堡/镇/湖/洞/浮岛）、14 种生物 AI（态度驱动）、15 种果实、变形与能力切换、24 果格背包与腐坏、主果窖 + 窖树仓库、7 条任务、图鉴、日夜、灰雾墙边界、死亡掉落与捡回、localStorage 存档。

原型未实现（文档中已设计）：混合形态、魔力胃、兽化残留、NPC 对话树、凤凰/母树化身形态、灰雾兽偷格、人鱼归还系统。

## 数据即设定

`game/data/fruits.js`、`game/data/creatures.js`、`game/data/world.js` 是**唯一的设定真源**：文档里的每个数字（果格数、失活时间、态度、区域半径）都来自这三个文件。改设定改数据，文档随之重生成。
