## 4. 垂直分层

谷地不是一张平面，是四层：

| 层 | y | 内容 | 到达方式 |
|---|---|---|---|
| **云顶** | 29–40 | 6 座浮岛、龙巢、凤凰环峰 | 飞行（猫头鹰/蝙蝠/萤蛾/凤凰/龙）或巨蛛爬壁 + 跳跃 |
| **冠层** | 20–28 | 树冠、钟塔顶、梁蛛的梁 | 跳跃 + 弹弹菇；或巨蛛爬树 |
| **地表** | 15–24 | 森林、镇、城堡、果园 | 步行 |
| **水下** | 0–14 | 镜湖、沉塔、人鱼村、水母田 | 水獭（闭气）→ 人鱼（水下呼吸） |

**镜湖深度**：湖心 y14 水面，湖底 y5。深 9 格——人形闭气 18 秒刚好够潜到沉塔窗口再上来，但不够进塔。这是"水獭果 → 人鱼梨"两级门禁的物理基础。

## 5. 场景细部

### 5.1 星坠堡（城堡）

湖心岛上，四塔一钟，地窖是果实温室。

- **钟塔** y34：全谷地最高的可站立点（浮岛除外）。任务"夜之翼"的验证点。
- **温室（地窖）** y18：玻璃顶（block 21），里面种着**不能采摘**的示范果树——它们是图鉴的"活教材"，也是唯一能看到"果实完整生长周期"的地方。
- **四塔**：分别对应四种稀有度展示。传说塔是空的，只有一行字：「这里放过一颗焰心果。它把另外三颗吃掉了。」
- 城堡外墙有**辉石灯**（block 14，自发光），夜里是谷地最亮的光源——萤蛾形态会被它拖过去（趋光副作用）。

### 5.2 低语林（森林）

矩形覆盖整个北半部。三层结构：

- **外缘**（z 60–72）：月光草地、蘑菇圈入口、狐狸洞。常见果：猫头鹰果、萤蛾果、狐李。
- **中段**（z 30–60）：古木、鹿径、倒木上的鹿茸菌果。鹿群活动区。
- **深处**：圣林（独立区域，见下）。

树的种类：橡（叶 7 / 暗叶 27）、松（针叶 8）、银（银叶 9，圣林专属）、柳（柳叶 28，湖边）。

### 5.3 蘑菇圈

直径 26 的空地，一圈 24 株荧光菇（block 76，自发光）。夜里整圈以 6 秒周期明灭。中央空地是**发光种子**最密集处，也是"窖树种"的主要来源。

### 5.4 蝙蝠洞·回声丘

山体掏空的三层隧道，总长约 120 格。

- 上层：洞顶倒挂蝙蝠果（block 41）。
- 中层：梁蛛巢，丝莓（block 49）。
- 下层：**根须隧道**，通往果园遗迹母树根系（第四/七章用）。
- 夜里进入会听到"合唱"——一整洞蝙蝠同时发声定位。变成蝙蝠后玩家会不由自主加入（画面边缘声波脉冲）。

### 5.5 镜湖

半径 34，湖心最深。

- **沉塔** (66,118)：塔顶在 y12（水面下 2 格），塔基 y5。窗台上结**人鱼梨**（block 47）。要摘必须能在水下呼吸。
- **人鱼村** (92,120)：y9，由水母田照明。人鱼敌视人形（attitude.human = hostile）。
- **水母田**：位置正好是沉塔的轮廓——从水面往下看，塔在发光。

### 5.6 果园遗迹·母树

一圈断墙（直径 30）+ 一株半枯母树。母树不结果，但**树根上结母树花蕾**（block 54，传说，不可食用）。

遗迹的梁柱由梁蛛三百年织的丝撑着——拆掉丝莓巢会让梁柱塌，露出地下的母树根系。

## 6. 果实门禁图（推进依赖）

```
  地表（步行）
    │
    ├─ 低矮根洞 ──→ 狐狸（dig/小体型）
    ├─ 蘑菇圈 ────→ 无门禁（教学区）
    │
    ├─ 镜湖浅滩 ──→ 水獭（swim 2.2 + 闭气 +25s）
    │      └─ 沉塔内部 ──→ 人鱼（breatheAir:false）
    │             └─ 人鱼梨 ──→ 解锁"湖的账"章节
    │
    ├─ 圣林边界 ──→ 独角兽（attitude: 人形 hostile，同种 calm）
    │      └─ 银角樱
    │
    ├─ 垂直洞壁 ──→ 巨蛛（climb）
    │
    ├─ 树冠 / 钟塔 ──→ 猫头鹰（fly 5.2）
    │      └─ 30m 以上 ──→ 任务"夜之翼"
    │
    └─ 云顶浮岛 ──→ 猫头鹰/蝙蝠/萤蛾（fly）或 巨蛛+弹弹菇（climb+jump）
           ├─ 焰心果（龙巢，龙 hostile）
           └─ 凤凰核（黄昏限定）
```

**关键设计**：圣林的钥匙不是"找到独角兽果"，而是"变成独角兽"。圣林里的独角兽对 `default`（人形）态度是 `hostile`，对 `self`（独角兽）是 `calm`。玩家必须真的以独角兽形态走进去——而银角樱本身在圣林里面。**先有鸡还是先有蛋**的解法：鹿径上的鹿茸菌果 → 雄鹿形态 → 独角兽对鹿是 `curious`（不攻击但不放行）→ 需要跟着鹿群混进去一次，在圣林边缘的倒木上找到第一颗银角樱。
