# 06 · 任务与进程

[English: ../en/06-quests-and-progression.md](../en/06-quests-and-progression.md)

## 1. 进程哲学

**没有等级。** 玩家的"进度"只有三件事：

1. **能进入的地形**（由形态决定）
2. **能装下的果实**（由背包与仓库决定）
3. **认得的果实**（由图鉴决定）

任务不是奖励管道，是**门禁的说明书**：每条任务都在教一个"新的身体能做什么"。

## 2. 原型任务（7 条，已实现）

| id | 名称 | 提示 | 教会什么 | 验证方式 |
|---|---|---|---|---|
| `q1` | 认识主果窖 | 去灯笼镇的果窖（按 E 打开），把任意果实存进去 | 仓库存在 + 腐坏倍率 | `stashes[0].items.length > 0` |
| `q2` | 三颗猫头鹰果 | 低语林的橡树洞里找 3 颗猫头鹰果 | 栖息地绑定 + 夜间视野 | 背包内 owlberry ≥ 3 |
| `q3` | 夜之翼 | 夜里吃下猫头鹰果，飞到 30 米以上 | 飞行 + 时间条 | `form==='owlberry' && y > 30` |
| `q4` | 镜湖的门票 | 变成雨蛙下水，在沉塔的窗台上取一颗蛙果 | 两级水门禁（闭气 → 皮肤呼吸） | 获得 frogpear |
| `q5` | 深鹿林的通行证 | 变成白尾鹿沿鹿径走进深鹿林，摘一颗鹿茸菌果 | 态度矩阵 = 通行证 | 获得 stagcap |
| `q6` | 云顶的旧梁 | 飞到云顶，在旧梁上摘一颗丝莓（梁蛛不欢迎客人） | 高度 + 一具会织丝的身体 | 获得 silkberry |
| `q7` | 温室的银丝网 | 去星坠堡的果实温室（地窖），找那张银丝隔层 | 背包升级：稀有及以上占格 −1 | 站在 greenhouse 6 m 内（y 在 −6…+10 带内） |

任务在图鉴面板（J）里显示为清单，完成时播报「✔ 完成：…」。**没有奖励弹窗，没有 XP**——奖励就是"你现在能去那里了"。

q4 完成时另外发放 `pouch2`（深果袋 +6 格）：镜湖一次潜水带回的蛙果是 4 格一颗，24 格的背包带不出有用的量。

## 3. 七个邀请（任务不是剧情）

没有主线，没有反派，没有结局。任务是一个**去使用一具身体的邀请**，也是游戏唯一的说明书：每一个任务教一道门——只能以一种方式到达的地方，或只能以一种方式带走的东西。

| # | 邀请 | 教什么 | 需要的身体 |
|---|---|---|---|
| q1 | 认识主果窖 | 果实会死；仓库存在 | 无 |
| q2 | 三颗猫头鹰果 | 采摘、果格、失活 | 无 |
| q3 | 夜之翼 | 飞行，以及空中的时间条 | 猫头鹰 |
| q4 | 镜湖的门票 | 呼吸、溺水、皮肤、脱水 | 雨蛙 |
| q5 | 深鹿林的通行证 | 形状不是伪装：深鹿林读的是身体 | 白尾鹿 |
| q6 | 云顶的旧梁 | 高度，以及一具会爬也会织丝的身体 | 猫头鹰（飞）或穿山甲（爬）+ 弹弹菇 |
| q7 | 温室的银丝网 | 稀有果少占一格 | 无 |

谷地没有任何东西在等着被拯救。七个都不做，谷地也照常：果实照样成熟，熊照样来偷，雾照样让人忘。

**七个全做完的状态**：玩家能抵达每一种栖息地、带得下需要的果、一眼读出果实。这就是全部的成长。

> 随设定简化（01）删除：母树的失忆、三个结局、以及只为它们存在的果实与生物。灰手套商会留着——它不是反派，是一个"把果运出去"的机构，而谷地的边界（01 §3）就是它的对手。

## 4. 支线（12 条，正式设计）

| 支线 | 触发 | 内容 |
|---|---|---|
| 雨后合唱 | 雨后在镜湖岸边听蛙 | 跟着最先开口的那只（老鼓）走，它能带你到沉塔唯一没被芦苇堵住的入口 |
| 鹿径不是路 | 跟一群白尾鹿走 | 鹿径一定通到水；沿路解锁 3 个隐藏窖树锚点 |
| 沉塔的铜铃 | 镜湖的门票（q4）之后 | 把窗台上的铜铃带回蛙鸣泽，老鼓认得它 |
| 熊的果窖 | 北岭发现熊挖的洞 | 里面是 300 年前失活的果核 —— 种下可复活 1 种失踪果 |
| 穿山甲的空洞 | 果园遗迹的土丘 | 挖开一个已经空了的洞：洞底有一整仓被搬空的果核，是谁搬的没人知道 |
| 梁蛛的账 | 果园遗迹 | 拆丝莓巢 → 梁柱塌 → 露出一条下到洞底的新路（捷径） |
| 钟摆的三颗 | 主果窖存猫头鹰果 | 解锁猫头鹰邮递（3 天 1 次，把远处的果叼回最近的仓库） |
| 灰雾里的空格 | 在灰雾边缘丢过一颗果 | 那颗果会出现在另一棵树上——不是同一棵，也不是同一种 |
| 老梅不吃的理由 | 存够 50 颗 | 灰熊无花果闻香事件：她只说"我闻过一颗。够了。" |
| 灰手套的账本 | 奎尔营地 | 显示哪些果被运出去了（图鉴补全线索） |
| 空果苗 | 种 20 颗空果核 | 15% 复活率，玩家自建的"复育园" |
| 旧梁上的名字 | 抵达云顶旧梁之后 | 梁上三百年前刻着的名字，不是你的，也不是任何人的 |

## 5. 图鉴（J 键）

三个页签：

1. **果实图鉴**：7 格（正式 40 格），未发现的显示为"？"。已发现显示：中文名、稀有度、占格、失活时间、栖息地、形态能力、副作用、lore。
2. **生物图鉴**：7 种，显示 dex 文案 + 对你的当前态度（实时，随形态变化）。
3. **任务清单**：当前任务的 hint，不显示奖励。

图鉴完成度是**唯一被记录的成长指标**，且不给任何数值奖励。

## 6. 死亡与失败

| 情况 | 处理 |
|---|---|
| 活力归零 | 在主果窖复活；**全部背包果实掉落在死亡点**（生成 drop 方块，可捡回） |
| 溺水 | 同上 |
| 脱水（雨蛙形离水 90 秒后） | 同上——两栖身体的溺不在水里，在岸上 |
| 坠落（y < −2） | 传回 y30 + 1.2 伤害（原型）；正式设计为"摔在最近的树冠上" |
| 灰雾墙 | 不死亡，只播报 + 小地图失效；正式设计为"走出去后随机丢失 1 个果实（永久）" |
| 时间条耗尽 | 无惩罚，只复原 |

**掉落可捡回**是刻意的：它把死亡变成"我东西落在那儿了，得回去拿"，而不是"读档"。这也让死亡和果实腐坏机制咬合——你回去得太晚，掉落的果全变果核了。

## 7. 时间

| 项 | 原型 | 正式 |
|---|---|---|
| 一天 | 420 s | 1200 s |
| 日出 / 黄昏 / 夜 | 6 / 18 / 21 时 | 同 |
| 夜的作用 | 夜行生物出洞、果实自发光可见、部分生物态度改变 | + 雨后蛙鸣、蘑菇圈明灭 |

时间不是压力源（玩家本人不会饿死），压力只来自**果实的保质期**。
