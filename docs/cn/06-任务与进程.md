# 06 · 任务与进程

[English: ../en/06-quests-and-progression.md](../en/06-quests-and-progression.md)

## 1. 进程哲学

**没有等级。** 玩家的"进度"只有三件事：

1. **能进入的地形**（由形态决定）
2. **能装下的果实**（由背包与仓库决定）
3. **认得的果实**（由图鉴决定）

任务不是奖励管道，是**门禁的说明书**：每条任务都在教一个"新的身体能做什么"。

## 2. 原型任务（7 条，已实现）

| id | 名称 | 提示 | 教会什么 | 验证方式 |
|---|---|---|---|---|
| `q1` | 认识主果窖 | 去灯笼镇的果窖（按 E 打开），把任意果实存进去 | 仓库存在 + 腐坏倍率 | `stashes[0].items.length > 0` |
| `q2` | 三颗猫头鹰果 | 低语林的橡树洞里找 3 颗猫头鹰果 | 栖息地绑定 + 夜间视野 | 背包内 owlberry ≥ 3 |
| `q3` | 夜之翼 | 夜里吃下猫头鹰果，飞到 30 米以上 | 飞行 + 时间条 | `form==='owlberry' && y > 30` |
| `q4` | 镜湖的门票 | 变成雨蛙下水，在沉塔的窗台上取一颗蛙果 | 两级水门禁（闭气 → 皮肤呼吸） | 获得 frogpear |
| `q5` | 湖底的田 | 吃下一颗水母花苞，变成水母，沉到镜湖湖底的果田 | 一具能憋 58 秒、自己会发光、在岸上走不动的身体 | `form==='jellybloom' && y < 11` |
| `q6` | 一颗棕熊果 | 在北岭岩坡上摘一颗棕熊果：它占 12 格，7 分钟就失活——把它带进仓库 | 传说果是一次搬运，不是一次收集 | 获得 bruinfig |
| `q7` | 温室的银丝网 | 去星坠堡的果实温室（地窖），找那张银丝隔层 | 背包升级：稀有及以上占格 −1 | 站在 greenhouse 6 m 内（y 在 −6…+10 带内） |

任务在图鉴面板（J）里显示为清单，完成时播报「✔ 完成：…」。**没有奖励弹窗，没有 XP**——奖励就是"你现在能去那里了"。

q4 完成时另外发放 `pouch2`（深果袋 +6 格）：镜湖一次潜水带回的蛙果是 4 格一颗，24 格的背包带不出有用的量。

q5 是唯一一条**验身体**而不是验果实的任务：人形闭气 18 秒也够摸到湖底摘一颗水母花苞，所以任务要的不是"你有一颗"，而是"你站在湖底，用一具能憋 58 秒、自己会发光的身体"。q6 反过来——它只验果实，因为传说果的难处不在能不能到，而在它占 12 格、7 分钟就失活：你得把它背回仓库。

## 3. 七个邀请（任务不是剧情）

没有主线，没有反派，没有结局。任务是一个**去使用一具身体的邀请**，也是游戏唯一的说明书：每一个任务教一道门——只能以一种方式到达的地方，或只能以一种方式带走的东西。

| # | 邀请 | 教什么 | 需要的身体 |
|---|---|---|---|
| q1 | 认识主果窖 | 果实会死；仓库存在 | 无 |
| q2 | 三颗猫头鹰果 | 采摘、果格、失活 | 无 |
| q3 | 夜之翼 | 飞行，以及空中的时间条 | 猫头鹰 |
| q4 | 镜湖的门票 | 呼吸、溺水、皮肤、脱水 | 雨蛙 |
| q5 | 湖底的田 | 憋得住的气，一具自己会发光、在岸上走不动的身体 | 水母 |
| q6 | 一颗棕熊果 | 传说果是物流问题：24 格里占 12 格，420 秒失活 | 棕熊（一步跨过 1.1 m 的岩坎），或者两条腿一级一级跳 |
| q7 | 温室的银丝网 | 稀有果少占一格 | 无 |

谷地没有任何东西在等着被拯救。七个都不做，谷地也照常：果实照样成熟，熊照样来偷，雾照样让人忘。

**七个全做完的状态**：玩家能抵达每一种栖息地、带得下需要的果、一眼读出果实。这就是全部的成长。

## 4. 没有支线

没有第二层内容。七个邀请就是全部任务：树洞里没有什么在等你，没有哪只具名的动物请你替它取回一样东西，旧梁上也没有一个等着被读出来的名字。

这一节曾经是一张 12 行的设计表。roster 和魔法简化之后，它成了整份文档里最不相称的东西：**每一行都没有实现**；而地图之所以许诺得比兑现的多，恰恰是因为这张表——会回应落石的空丘、果园里的土丘、还立着的旧梁、没有门的深林，每一处都在替一个永远不会来的任务留着位置，其中两行还依赖谷地已经没有的动物。

替代它的是生物那一章早就写下的那句话：谷地扣着自己的动物，直到每一种都带着一颗果、一个生态位、一扇只有它能开的门回来。在那之前，一个地方可以**就是**在那儿——黑、深、什么用都没有。那不是要填的洞，那就是灰雾同款的缺席。

如果某个地方将来真的挣到一个任务，那个任务必须教一道门：只有某种身体到得了的地方，或只有某种身体带得动的东西。这是这个游戏唯一有的任务类型，而这样的任务一共七个。

## 5. 图鉴（J 键）

三个页签：

1. **果实图鉴**：4 格，未发现的显示为"？"。已发现显示：中文名、稀有度、占格、失活时间、栖息地、形态能力、副作用、lore。
2. **生物图鉴**：4 种，显示 dex 文案 + 对你的当前态度（实时，随形态变化）。
3. **任务清单**：当前任务的 hint，不显示奖励。

图鉴完成度是**唯一被记录的成长指标**，且不给任何数值奖励。

## 6. 死亡与失败

| 情况 | 处理 |
|---|---|
| 活力归零 | 在主果窖复活；**全部背包果实掉落在死亡点**（生成 drop 方块，可捡回） |
| 溺水 | 同上 |
| 脱水（雨蛙形离水 90 秒后） | 同上——两栖身体的溺不在水里，在岸上 |
| 坠落（y < −2） | 传回 y30 + 1.2 伤害（原型）；正式设计为"摔在最近的树冠上" |
| 灰雾墙 | 不死亡，只播报 + 小地图失效；正式设计为"走出去后随机丢失 1 个果实（永久）" |
| 时间条耗尽 | 无惩罚，只复原 |

**掉落可捡回**是刻意的：它把死亡变成"我东西落在那儿了，得回去拿"，而不是"读档"。这也让死亡和果实腐坏机制咬合——你回去得太晚，掉落的果全变果核了。

## 7. 时间

| 项 | 原型 | 正式 |
|---|---|---|
| 一天 | 420 s | 1200 s |
| 日出 / 黄昏 / 夜 | 6 / 18 / 21 时 | 同 |
| 夜的作用 | 夜行生物出洞、果实自发光可见、部分生物态度改变 | + 雨后蛙鸣、蘑菇圈明灭 |

时间不是压力源（玩家本人不会饿死），压力只来自**果实的保质期**。
