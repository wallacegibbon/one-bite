# 00 · 总览与设计支柱

[English: ../en/00-overview-and-design-pillars.md](../en/00-overview-and-design-pillars.md)

## 1. 原始需求（用户给定，不可违背）

1. 哈利波特式的魔法探索游戏，**体素风格**。
2. 场景：**城堡、森林、湖、天空**，可自由探索。
3. 森林里有**独角兽、猫头鹰、蝙蝠**等动物，以及**蘑菇、发光种子**等魔法植物；湖里有**人鱼**；天空有**龙**（稀有）。
4. **没有魔杖**。核心魔法道具是**魔法果实**：吃下后变成果实对应的动物，一段时间后复原。每种动物的果实只在它自己的栖息地出现。
5. 玩家有一个**魔法背包，容量有限**；**越稀有的果实占的空间越大**，所以一次装不下太多。
6. 玩家有一个**固定位置的仓库**；仓库**可以新建**，但**具体机制未定**——这是本项目要补完的设计。

## 2. 设计支柱（Pillars）

### P1 · 魔法是吃下去的，不是挥出来的
没有魔杖、没有咒语、没有手势。所有超自然能力都来自"把一段别处的生命吃进自己身体"。
这条支柱直接决定：施法动画 = 咬；施法材料 = 果实；施法代价 = 副作用 + 时间条。

### P2 · 身体就是钥匙
地形不是被"炸开"的，是被"变成合适的形状"通过的。
低矮的根洞只有狐狸能进；深水只有人鱼能待；垂直洞壁只有巨蛛能爬；云顶只有龙或猫头鹰能到。
**推进 = 找到果 + 装得下果 + 撑到那里。**

### P3 · 容量是唯一的稀缺货币
没有金币、没有体力条、没有能量。玩家所有的取舍都发生在"24 个果格怎么排"这一件事上。
稀有果占格大 → 想带传说果就得放弃两颗常见果 → 而常见果是"探路耗材"。

### P4 · 果实是活的，会死
果实从被摘下的那一刻开始倒计时。失活后变成**果核**，不能吃，但能种。
这条把"囤积"变成"流失"，把"仓库"变成"必须持续照料的地方"，也把"浪费"变成"种植"。

### P5 · 谷地不配合你
每种动物对"你现在的形状"有自己的态度。变成独角兽，鹿会好奇，狐狸会被顶穿，龙会来打你。
变形不是纯增益，是**换一张社会身份**。

## 3. 反目标（明确不做）

| 不做 | 原因 |
|---|---|
| 战斗 build / 技能树 | 能力全部来自果实，成长体现在"能去哪里、装得下什么" |
| 等级与经验值 | 与 P3 冲突：等级会让容量变得无关紧要 |
| 魔杖（哪怕作为装饰） | 支柱 P1。谷地外的人用魔杖，但魔杖在谷地内不工作——这条是世界观悬念 |
| 建造房屋 / 自由建造 | 仓库机制（见 05）用"种"代替"建"，保持世界是有机的 |
| 死亡惩罚数值化 | 死亡只掉落果实到原地，鼓励"回去捡"而不是"读档" |
| 时间压力 / 生存饥饿 | 只有果实有保质期，玩家本人没有 |

## 4. 体验目标（要让玩家说出的话）

- "我背包满了，但前面就是龙巢——我该扔哪一颗？"
- "原来这个洞要变成蜘蛛才进得去。"
- "我把它存进果窖，结果忘了三周，全变成果核了。"
- "我种下的果核长成一棵树了，那里以后会有我自己的果园。"
- "独角兽不攻击我——因为我真的是独角兽。"

## 5. 玩家幻想

不是"强大的巫师"，而是**"能变成任何东西的采集者"**。
一个背着筐、嘴里叼着果子、在谷地里到处找路的人。学院（星坠堡）存在，但它不教你法术，它教你**认果**。

## 6. 单次游玩节奏（15 分钟切片）

| 分钟 | 事件 |
|---|---|
| 0–2 | 从最近的仓库出发，检查背包余量与果实剩余时间 |
| 2–6 | 前往目标区，路上顺手采 1–2 颗常见果（占格但便宜，是"耗材"） |
| 6–9 | 遇到门禁地形 → 吃下对应果实 → 用新身体通过 |
| 9–12 | 在门禁另一侧拿到稀有果（占 4–12 格，背包瞬间紧张） |
| 12–15 | 决定：走回仓库 / 就地种下果核 / 冒险绕路。时间条与腐坏条同时逼近 |

## 7. MVP 边界（原型范围）

**在 MVP 内**：地形生成、自由行走/游/飞、果实采摘与腐坏、背包容量、变形与能力切换、生物态度、固定仓库 + 野外仓库、日夜、任务、图鉴、存档、身份层（编号 / 称呼 / 名字，见 03 §6）。

**明确不在 MVP**：NPC 对话树、混合形态、多人、载具、天气、建造、小地图以外的 UI 动效、程序化音频。
