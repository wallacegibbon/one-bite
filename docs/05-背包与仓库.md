# 05 · 背包与仓库机制

> **这是原始需求中唯一未定的部分**：「玩家有一个固定位置的仓库；仓库可以新建，但机制未定。」
> 本篇给出 3 个候选方案、评估、以及最终推荐设计（已在原型中实现核心部分）。

## 1. 问题定义

已知约束（不可改）：

1. 背包容量有限，**稀有果实占用更大空间**。
2. 玩家有一个**固定位置**的仓库。
3. 仓库**可以新建**。

需要回答的问题：

- Q1 新建仓库的**成本**是什么？（钱？材料？果实？任务？）
- Q2 新建仓库能放在**哪里**？（任意地点？特定锚点？）
- Q3 多个仓库之间**怎么转移**？（传送？搬运？邮寄？）
- Q4 仓库会不会**退化/被破坏**？
- Q5 怎么防止玩家"建 20 个仓库把谷地变成储物柜海洋"？

## 2. 三个候选方案

### 方案 A · 钱与地产（传统）

用果实换钱，钱买地皮，地皮上建标准仓库。

| 优 | 劣 |
|---|---|
| 玩家熟悉，实现简单 | **与 P3 冲突**：一旦有钱，容量焦虑消失 |
| 可做地产升级线 | 果实变成货币 → 玩家会囤积待价而沽，与"果实会死"矛盾 |
| | 仓库是"箱子"，与世界无机关联 |
| | Q5 无解：仓库数量只受钱限制 |

**结论：否决。** 它把整个游戏的稀缺货币从"果格"换成了"钱"。

### 方案 B · 背包即仓库（无固定仓库）

取消仓库，改为背包可升级 + 死亡/回城时果实自动"沉降"到角色身上。

| 优 | 劣 |
|---|---|
| 极简，无 UI 负担 | **直接违反需求**（需求明确说有固定位置仓库） |
| | 没有"回窖"这个节奏点，游戏失去呼吸 |
| | 无法表达"果实会死"——果实永远在你身上就不会腐坏 |

**结论：否决。**

### 方案 C · 仓库是活的（推荐）

**仓库不是造出来的，是种出来的。**

果实会死 → 死后果实变果核 → 果核能种 → 种下的果核长成**窖树**：一棵中空的、24 果格的活仓库。

这一条同时回答了 Q1–Q5：

- Q1 成本 = 一颗果核（你本来就会得到）+ 时间（它要长）
- Q2 地点 = 任何能种活的地方（有土、有光、离母树根系不太远）
- Q3 转移 = **猫头鹰邮递**（见 §5）
- Q4 会退化 = 窖树腐坏速度 1/3（不是 0），而且**獾与窃果贼会来偷**
- Q5 上限 = **最多 3 棵窖树**，理由是世界观的而非数值的：「窖树最多 3 棵——谷地记不住更多地方。」

**结论：采用。**

## 3. 最终设计：三层存储

| 层 | 名称 | 格数 | 腐坏倍率 | 数量 | 位置 |
|---|---|---|---|---|---|
| **随身** | 魔法背包 | **24**（可升到 36） | **×1.0** | 1 | 身上 |
| **固定** | 灯笼镇·主果窖 | **96** | **×0.1** | 1（固定） | (136,134)，永久 |
| **野外** | 窖树 | **24** | **×0.33** | **最多 3** | 玩家种植 |

### 3.1 魔法背包

- 24 果格。果实按稀有度占 1/2/4/7/12 格。
- 腐坏 ×1.0 —— 背包是**倒计时中**的空间。
- 升级（三条，各 +6 格或规则改动）：
  | 升级 | 效果 | 来源 |
  |---|---|---|
  | 副果袋 | +6 格 | 灯笼镇老梅的谢礼 |
  | 深果袋 | +6 格 | 沉塔里的防水皮囊 |
  | 银丝隔层 | 稀有及以上果实占用 **−1** 格 | 城堡温室的银丝网 |
- 上限 36 格 = 3 颗传说果。银丝隔层让"稀有 4→3、极稀 7→6、传说 12→11"，于是 36 格能装 3 颗传说 + 余量。

**为什么背包不做得更大**：24 格 = 2 颗传说果。这个数字让"带不带龙果"永远是一次取舍。

### 3.2 主果窖（固定仓库）

- 位置固定：灯笼镇 (136,134)，y20。世界生成时就存在，不可移动、不可摧毁。
- 96 格，腐坏 **×0.1**（1500 s 的常见果在窖里能放 15000 s ≈ 4 小时游戏内约 36 天）。
- 交互：走近 3.2 m 按 E → 左右两栏（背包 / 果窖），点击或方向键 + E 转移。
- 它是**唯一的"长期保存"**：只有这里能让稀有果活得比一次远征更久。
- 叙事功能：果窖是谷地的**记忆器官**。老梅说：「果窖不是放果子的地方，是放'以后'的地方。」

### 3.3 窖树（野外仓库）—— 新建仓库的机制

**建造流程**

```
  果实失活 → 果核(kind:'pit')            或  获得「窖树种」(cellarseed, 稀有, 4 格)
        │                                        │
        └────────── 手持果核/窖树种，按 R 种下 ──┘
                        │
              校验：脚下是土/苔土/沙、上方 2 格空、离其他窖树 ≥ 20 m
                        │
                  长成窖树（block 79 树干 + 77 核心，自发光）
                        │
                  24 果格 · 腐坏 ×0.33 · 计入 3 棵上限
```

**窖树的规则**

| 规则 | 数值 | 理由 |
|---|---|---|
| 上限 | 3 棵 | 「谷地记不住更多地方」 |
| 最小间距 | 20 m | 根系不重叠；也迫使玩家分散布点 |
| 腐坏 | ×0.33 | 窖树是活的，不是地窖。放里面的果只能撑 1/3 的背包时长 |
| 被偷 | 每游戏日 1 次判定，30% 概率被獾/窃果贼偷走 1–3 颗；**玩家若在 45 m 内则必定赶走，不丢东西** | 野外仓库必须**常回来看** |
| 摧毁 | 灰熊形态可拆（拆=掉落全部物品）；龙形态喷火 = 全部物品失活 | 让 strength 形态有实际用途 |
| 不可移动 | 窖树死了就是死了，物品散落 | 没有"打包仓库" |

**为什么窖树腐坏不是 0**：如果野外仓库零衰减，玩家就会在每张地图建一个，容量焦虑消失。×0.33 意味着窖树是**中转站**，不是**保险柜**。

## 4. 存储的经济学（一张表看懂取舍）

一颗**人鱼梨**（稀有，4 格，900 s）的寿命：

| 存放处 | 有效寿命 | 相当于游戏内 |
|---|---|---|
| 背包 | 900 s | 2 天 |
| 窖树 | 2700 s | 6.4 天 |
| 主果窖 | 9000 s | 21 天 |

一次"镜湖 → 灯笼镇"的往返约 3–4 分钟。所以：

- 人鱼梨**不能**从镜湖一路走回果窖（900 s 够，但路上还要打洞、下水、变形）。
- 必须在镜湖附近种一棵窖树中转 → 这就是"新建仓库"的真实动机：**不是贪多，是路程比保质期长。**

## 5. 仓库间转移

### 5.1 手动搬运（默认）

背包就是运输车。24 格里扣掉路上要用的耗材（蘑菇、发光种子），实际运力约 18–20 格。

### 5.2 猫头鹰邮递（窖树 ↔ 主果窖）

- 前提：你在主果窖存过至少 1 颗猫头鹰果（解锁"钟摆"）。
- 对窖树按 E 时多一个选项「让钟摆叼走 1 颗」。
- 每次 1 颗，**3 个游戏日后送达**主果窖。
- 送达时果实**已经腐坏 3 天**（按主果窖 ×0.1 计），所以邮递只适合稀有度 ≥ 稀有的果。
- 失败率 10%：「钟摆没有回来。第四天它自己飞回来了，嘴里是空的。」
- 实现补充：**同时在途最多 3 颗**（钟摆一次叼不了更多）；若送达时主果窖已满，钟摆会把果实**叼回原窖树**而不是丢在地上；解锁状态（`_owlUnlocked`）与在途队列（`posts`）都进存档。

设计意图：邮递**不消除搬运**，只是把"最珍贵的那一颗"单独运走。它比搬运慢、比搬运贵（要喂猫头鹰），但它是唯一不需要你亲自走一趟的方式。

### 5.3 明确不做

- ❌ 仓库间传送（会摧毁地图意义）
- ❌ 无限容量（会摧毁 P3）
- ❌ 仓库升级成无限格（主果窖 96 格是硬上限，不可升级）

## 6. 反囤积：三条互相咬合的闸门

| 闸门 | 机制 | 效果 |
|---|---|---|
| **失活** | 果实必然倒计时 | 囤积 = 浪费 |
| **果核化** | 失活不消失，变果核（占格减半） | 浪费变成**种植机会**，负面情绪转为长线行为 |
| **窖树上限 + 被偷** | 野外存储有限且有风险 | 玩家必须**周期性回访**，世界保持存在感 |

这三条把"仓库"从静态 UI 变成**需要经营的、会背叛你的、会长出树的东西**。

## 8. 一句话总结

> **仓库不是造出来的建筑，是种出来的树。你之所以要种它，不是因为背包小，而是因为谷地比一颗果实的寿命大。**
