# 07 · 美术 · 音频 · 技术方案

## 1. 美术方向

**体素，但不是 Minecraft。** 参考：《Minecraft》的方块语言 + 《Trove》的高饱和调色 + 吉卜力的"植物是有意图的"。

三条硬规则：

1. **一切植物都有"想做的事"**：果实自发光（想被看见）、藤蔓向下（想找水）、蘑菇成环（想圈地）。
2. **建筑是长出来的，不是砌的**：灯笼镇的房子是木框架 + 苔土填墙；星坠堡是城砖 + 辉石灯；果园遗迹靠梁蛛的丝撑着。
3. **光只有三种来源**：太阳/月、辉石与余烬（自发光方块）、生物（发光形态、水母、萤蛾、果实）。**没有环境补光**——夜里没带荧光菇就是真的看不见。

### 面光照（烘焙，非实时）

| 面 | 亮度 |
|---|---|
| +Y（顶） | 1.00 |
| +Z | 0.88 |

| −X | 0.66 |
| −Z | 0.58 |
| −Y（底） | 0.42 |

AO 四档：`[1.00, 0.78, 0.60, 0.46]`，按顶点三个邻块（边、边、角）计算。

### 生物模型

体素部件拼装，每部件一个网格 + 一个 pivot + 一种动画：

| 动画 | 用途 | 公式 |
|---|---|---|
| `flap` | 翅 | `rz = sin(t·spd)·amp`，amp 0.85（飞）/ 0.12（走） |
| `walk` | 腿 | `rx = sin(t·gait + phase)·move·0.75` |
| `wag` | 尾 | `ry = sin(t·1.6)·(move·0.5+0.12)` |
| `bob` | 头/身 | `dy = sin(t·2.2)·(move·0.12+0.05)` |
| `sway` | 鳍/羽 | `rz = sin(t·2.4)·0.28` |

15 个模型：human, owl, bat, moth, otter, fox, deer, jelly, merfolk, unicorn, spider, bear, dragon, veilbeast, phoenix。
第一人称手部 9 种：hand, talon, wing, paw, hoof, fin, claw, tentacle, shadow。

## 2. 音频方向（未实现，正式设计）

**没有配乐，只有"环境 + 材质"。**

| 层 | 内容 |
|---|---|
| 底噪 | 风（云顶最强）、水（镜湖）、滴水（洞穴）、叶响（圣林"没有风也会响"） |
| 生物 | 蝙蝠合唱（12 声部循环，玩家变蝙蝠时加入第 13 声部）、猫头鹰单音、人鱼低频和声（水下才听得见） |
| 交互 | 采摘 = 一声"啵"；失活 = 干裂声；变形 = 骨节重组 + 一次吸气 |
| UI | 图鉴翻页 = 纸；果窖开 = 木门 |
| 危险 | 灰雾墙内所有声音被"吸掉"（低通截止随深度降到 400 Hz） |

**变形时的音频规则**：变形瞬间，当前形态对应生物的叫声以玩家位置为中心播放，并持续整个形态期（音量随移动变化）。这让玩家"听见自己是什么"。

## 3. 技术方案（原型）

### 3.1 零依赖自研 WebGL1 渲染器

为什么不用 three.js：原型必须能**双击 `game/index.html` 直接跑**（`file://` 协议下 ES module 会被 CORS 拦），且体素渲染的需求很窄。

全部代码为经典 `<script src>` 全局脚本，挂在 `window.FRUTARIA` 命名空间下。

| 文件 | 职责 |
|---|---|
| `src/engine.js` | mat4、MeshBuilder、着色器、Renderer（视锥剔除、天空、粒子） |
| `src/world.js` | 方块表、体素存储、分块网格化（含 AO）、DDA 射线拾取 |
| `src/worldgen.js` | 值噪声/fbm 地形 + 结构生成（城堡/镇/洞/湖/浮岛/森林） |
| `src/models.js` | 15 生物模型 + 9 手部 + 部件动画矩阵 |
| `src/entities.js` | Player（AABB 碰撞/呼吸/飞行）、Creature（态度驱动 AI）、Particles |
| `src/game.js` | 主逻辑：果实/背包/腐坏/仓库/任务/存档/渲染循环 |
| `src/ui.js` | HUD、旋转小地图、背包条、仓库面板、图鉴、帮助、死亡 |
| `src/main.js` | 输入绑定、主循环、启动流程 |
| `data/*.js` | **设定真源**：fruits / creatures / world |

### 3.2 渲染

- **分块**：16×48×16，10×10 = 100 块。每块 5 个网格：`[不透明, 自发光, 水, 道具, 道具自发光]`。
- **面剔除**：固体不透明邻居的面不生成。
- **视锥剔除**：从 MVP 提取 6 个平面（列主序取行：`row3 ± row0/1/2`），按块中心球体测试。
- **自发光层**：单独网格，`emisBoost` 提升，不受日夜光照影响。
- **水**：单独网格，混合 + 顶点波动（`sin(x*0.6+t)+sin(z*0.45-t*1.3)`）。
- **天空**：全屏四边形，程序化渐变 + 日月盘 + 星。
- **雾**：指数雾，颜色随日夜；水下换色换密度；灰雾墙内换灰色浓雾。
- **粒子**：单 draw call，900 个上限（发光种子、水花、变形烟雾）。

原型实测（1280×720，SwiftShader 软渲染）：100 块全建，约 20–30 万三角面，47–400 draw call，**54–60 fps**。

### 3.3 数据与存档

- 体素：`Uint8Array(w*h*d)` = 160×48×160 = 1.23 MB。
- `maxY` 高度图：`Uint8Array(w*d)`，加速网格化与 AI 寻地。
- 存档：`localStorage['frutaria.save.v1']`，只存**方块差分**（`diffs`）+ 玩家 + 背包 + 仓库 + 重生队列（`regrow`）+ 背包升级 + 任务 + 时间。实测 1.7 KB。

### 3.4 已知技术债

| 项 | 说明 |
|---|---|
| 无遮挡剔除 | 洞穴内仍绘制外部块 |
| 无异步网格化 | 分块网格化在启动时按 22 ms 预算分帧，但玩家改动会同步重建 |
| 生物无寻路 | 只用"朝目标 + 高度修正 + 撞墙随机偏转"，会卡在地形 |
| 无 LOD / 无流式加载 | 160³ 世界全常驻内存，正式规模需 chunk streaming |
| 无 NPC 对话树 | 老梅 / 托班 / 白露只有日志文本，没有分支对话 |
| 猫头鹰邮递未实现 | `docs/05` 设计的跨仓转运（1 件 / 3 游戏日 / 10% 丢失）只有文档 |
| 窖树未被掠夺 | 獾与灰手套的"每游戏日 30% 掠夺判定"未接入 |

## 4. 测试

|---|---|

| `game/test/input.js` | 真实按键：走 / 跳 / 飞 / 时间条 / 灰雾墙边界 |
| `game/test/upgrade.js` | 背包升级：24→30→36 果格、银丝隔层 −1、q7 触发、存档往返 |
| `game/test/shot.js` | 单张截图（可指定坐标 / 朝向 / 变形 / 时间），用于肉眼检查 |
