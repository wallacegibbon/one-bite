# 一口 · ONE BITE

**中文** · [English: README.md](README.md)

**体素**魔法探索游戏。这个世界只有一种魔法，它是一种果实。

吃下它，你会变成它所记得的动物，一段时间后复原。你会完整继承那具身体——所有的能力，所有的脆弱。每种动物的果实只长在它自己的地盘上。你的魔法背包只有 **24 个果格**，而越稀有的果实越大颗——**你带不走所有魔法**。

你实际在做的事：找果子，躲开能伤到你的东西，走到没有对的身体就到不了的地方。这背后没有等着被揭开的谜。

- 完整设定文档：[`docs/cn/`](docs/cn/README.md)（中文）· [`docs/en/`](docs/en/README.md)（English）
- 可玩原型：[`game/index.html`](game/index.html)

## 运行原型

零依赖，直接双击 `game/index.html`（或）：

```bash
cd game && python3 -m http.server 8000   # 然后打开 http://localhost:8000/
```

需要支持 WebGL 1.0 的浏览器。首次加载会分帧生成 100 个区块（约 1–3 秒）。

## 原型是什么

- **160×48×160 体素世界，11 个区域**：星坠堡（湖心岛上的城堡）、低语林、蘑菇圈、回声丘、深鹿林、北岭·鹰喙峰、镜湖（水下 / 沉塔 / 蛙鸣泽）、灯笼镇、果园遗迹、云顶浮岛（6 座），以及作为边界的灰雾墙。
- **3 种果实、3 具身体，一个生态位一只动物**：猫头鹰、雨蛙、棕熊。稀有度梯子有 5 档，谷地目前只长其中 3 档（常见 / 稀有 / 传说）；一颗果实占掉 24 格里的 1、4 或 12 格。
- **变形**：一次只有一具身体。吃下第二颗果实就把身上这具换掉；代价是提前结束的那具身体，和你吃掉的那颗果实。
- **代码真的在读的身体能力**：碰撞体型、走 / 游 / 飞速度、跳跃力、自动上台阶、滑翔（猫头鹰松开按键就以你三分之一的速度往下掉）、闭气时长、水下呼吸、离水会干的皮肤、夜视（同一双眼睛在白昼被晃白）、隐蔽、威吓半径、不怕北岭的冷、视野角、第一人称的手。
- **4 种生物、30 只**（其中 3 种是能穿的身体），态度驱动 AI：它们对"你现在穿着的形状"反应，而且没有任何动物会主动猎你。危险来自水、高度、寒冷、雾、镜湖的灯，以及你这具身体做不到的事。
- **仓库**：24 果格背包、主果窖（96 格，腐坏 ×0.1）、野外最多 3 棵窖树（24 格，×0.33，彼此至少相距 20 m）。
- **背包升级 3 件**：副果袋 +6（第一条任务）、深果袋 +6（沉塔）、银丝隔层（稀有果实占格 −1，温室）→ 满级 36 格。
- **腐坏与重新结果**：摘下来的果实会失活（越稀有越快），果核可以种下；结果点按稀有度重新结果（1 / 1.5 / 2 / 2.5 / 3 游戏日，±20%），重生队列入档。
- **窖树掠夺**：每游戏日一次判定，30%，熊或偷果贼拿走 1–3 颗；你在 45 m 内必定赶走。主果窖有老梅看守，不被抢。
- **猫头鹰邮递**：窖树 → 主果窖，每 3 游戏日 1 颗，10% 丢失，在途最多 3 颗。
- **6 条任务**、图鉴、420 秒一天的日夜循环、自发光果实与植物、粒子、旋转小地图、死亡掉落与捡回、localStorage 存档。
- **身份层，主角没有固定名字**：稳定 `id`（世界只记这个）、按作为获得的"称呼"（文案只用它）、可选的玩家自定名字（按 `N`）。
- **界面语言可切换**（中文 / English，按 `L` 或点 HUD 按钮）：界面文案每种语言一张扁平表，设定文案仍以 `cn`/`en` 成对字段留在记录自己身上，存档里不写任何翻译（07 §3.4）。

## 文档已设计、原型还没做

NPC 对话树；窖树被熊拆毁；雨蛙形皮肤湿度的 HUD 条（脱水本身在跑）；程序化音频。文档里还列着几条代码尚未收取的身体代价：爪打不开仓库、体重压裂薄冰、太小够不到高处的果实。`game/test/reach.js` 会把"数据里声明了、代码里没读"的字段全部打印出来，所以这张单子只能靠真的把东西做出来才能缩短。

## 已从设计中删除，不在路线上

混合形态、魔力胃、兽化残留、12 条支线任务、那家贸易公司和它的代理人、主角的果实清单与它的隐藏揭示、空果、偷果贼陷阱、`strength` 与 `tongue` 两个能力，以及穿山甲、鹿、蜘蛛、灯水母四种动物。这些是决定，不是没做完的活；前四项一旦在任何一种语言里重新出现，`game/test/docs-sync.js` 就会让构建失败。
